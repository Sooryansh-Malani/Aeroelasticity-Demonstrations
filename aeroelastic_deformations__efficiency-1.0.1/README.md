Computs static aeroelastic deformations and aeroelastic efficiency of a wind-tunnel model at different flow conditions, compute the wing’s divergence speed, and investigate the effect of wing sweep on static aeroelasticity. The wing will be modeled as a beam, using finite-elements, and the aerodynamics will be computed via ’Strip Theory’.

User can change the sweep angle, GJ and EI of the wing.
