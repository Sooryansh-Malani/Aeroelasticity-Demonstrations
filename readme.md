This is the directory containing the files used for the Aeroelasticity demonstration.

I have added the pdf file having an overview of the explanation of the codes in aeroelastic deformation efficieny of a wing, but the notes are based on my understanding of the work, and do not reflect the actual work, which has to be inferred from the code in case of any confusions.

Also, I had made some corrections in the aeroelastic deformation efficieny of a wing repository code, which were not there in the original version. I am not a 100% sure about if I had made the right corrections, some of them were regarding the addition of a 1/2 factor over some assembly quantities and one of them was used to modify the AFC matrix. In case of any mistake from my end, feel free to reach out and correct.

Visual demonstrations were added in both repositories, they were added with the assistance of claude ai, and were not a part of the original work the other codes are derived from.

Although not an extensive guide to be followed, but the codes can be used as a starting point to get some form of an approximate answer or as a visualisation tool.

The works this repository has been borrowed form are available on :
1. https://in.mathworks.com/matlabcentral/fileexchange/182982-airfoil-aeroelastic-flutter-analysis
2. https://in.mathworks.com/matlabcentral/fileexchange/75087-aeroelastic-deformations-efficiency-divergence-speed
